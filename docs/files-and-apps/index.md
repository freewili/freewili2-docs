# Files & Apps

How storage works on FREE-WILi 2, how to move files between the device and a
host computer, what an "app" is on the device's own screen, and where
scripts and add-on apps come from.

- [Transferring files](transferring-files.md) covers the device's storage
  layout and the ways to get files on and off it.
- [Running apps](running-apps.md) covers what an app is on this device,
  launching one from the on-device list, and what scripts are.
- [App marketplace](app-marketplace.md) covers WiliApps, FREE-WILi's
  distribution point for community and third-party apps.

If you haven't yet, [Screen and buttons](../start-here/screen-and-buttons.md)
in Start Here is the place to learn the on-device app list and navigation
model this section assumes.
