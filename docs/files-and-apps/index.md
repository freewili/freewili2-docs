# Files & Apps

How storage works on FREE-WILi 2, how to move files between the device and a
host computer, what a real **app** is compared to onboard screen
views, and where scripts and add-on apps come from.

- [Transferring files](transferring-files.md) covers the device's storage
  layout and the ways to get files on and off it.
- [Running apps](running-apps.md) covers what an app is on this device,
  getting a UF2 onto the card, and launching it.
- [App marketplace](app-marketplace.md) covers WiliAppsGalore, the
  on-device app for downloading community and third-party apps.

If you haven't yet, [Screen and buttons](../start-here/screen-and-buttons.md)
in Start Here is the place to learn the on-device panel list and navigation
model this section assumes.
