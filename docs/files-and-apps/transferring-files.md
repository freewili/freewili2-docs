# Transferring files

## Storage layout

FREE-WILi 2 has two microSD cards: one for the device's own file system
(scripts, sounds, images, app data), and one dedicated to the Raspberry Pi
CM0's Linux install. They're independent — files on one aren't visible from
the other.

## The on-device Files panel

**System > Files** is the on-device file browser — see
[Screen and buttons](../start-here/screen-and-buttons.md#the-top-level-panels)
for what it does and how finished it is.

## Getting files on and off

### The Fastest: The USB SDCard Reader

From the main screen you can mount and unmount the SDCard. Touch the main screen and it will show the theme selector. to the right of the theme there are two buttons for mounting or unmounting the card on the free wili device.

When unmount from the Free Wili the SDCard will connect to the USB Card reader. The card will appear in the host system as storage that you can use like any SDCard.

### The Slowest: Over the default USB channel

Availible in the OneWili API and the Free Wili Gui app. You can transfer files using the direct USB Connection.
