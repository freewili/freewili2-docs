# Hardware

Reference material for FREE-WILi 2's physical hardware: the GPIO pinout, the
physical connectors around the case, the Orca expansion module system, and
the Porpoise Purpose Module.

- [Pinout](pinout.md) — the 20-pin GPIO header and 10-pin analog header,
  pin by pin.
- [Connectors](connectors.md) — every physical port on the case and what
  it's for.
- [Orca modules](orca-modules.md) — the expansion module concept and the
  modules currently available.
- [Porpoise Purpose Module](porpoise-purpose-module.md) — the small
  FREE-WILi module with CAN FD, level-shifted UART / SPI / I²C / GPIO and
  the same firmware, console and OneWili API as FREE-WILi 2.
