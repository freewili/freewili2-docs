# Help

Troubleshooting, recovering a device that won't boot, and answers to
questions that come up often.

- [Troubleshooting](troubleshooting.md) — the device isn't detected, the
  screen is blank, the battery won't charge, or a firmware update didn't
  take.
- [Recovery mode](recovery-mode.md) — getting into the bootloader and
  recovering a unit that won't start normally.
- [FAQ](faq.md) — shorter questions that don't need a full page.

If none of this covers your issue, the
[FREE-WILi Discord](https://discord.com/invite/XJRBUCX62z) is where the team
and other owners answer questions day to day.
