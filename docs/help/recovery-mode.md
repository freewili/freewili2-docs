# Recovery mode

Most issues can be solved with power up and down sequence. Or a [Firmware update](../start-here/firmware-update.md).

## Some Tricks

Pressing yellow, green, and blue buttons at the same time will reset the main and display processors.

## Everyday options

The  main console hardware offers other options to reboot, recover or enter the bootloader.
